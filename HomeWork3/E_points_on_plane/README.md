# E. Точки на плоскости

|                     |                                  |
|---------------------|----------------------------------|
| Ограничение времени | 1 секунда                        |
| Ограничение памяти  | 256Mb                            |
| Ввод                | стандартный ввод                 |
| Вывод               | стандартный вывод                |

Точки с целочисленными координатами из 1-го квадранта помечаются числами 0, 1,
2, … слева направо и снизу вверх таким образом, что очередной точке
приписывается минимальное число, отсутствующее в вертикали и горизонтали,
проходящей через точку. Первой помечается точка (0, 0).

Допустим, мы хотим пометить точку $(i, j)$. Это значит, что все точки,
находящиеся ниже и левее относительно неё, уже помечены. Тогда рассмотрим набор
из чисел в $i$-й строке и $j$-м столбце (вместе). Отметкой точки $(i, j)$ будет
минимальное неотрицательное число, которое не содержится в этом наборе.

Написать программу, которая:
1. По заданным координатам $x$ и $y$, $x \ge 0$, $y \ge 0$, $x$, $y$ — целые,
   определяет пометку точки.
2. По заданной координате $x$ и пометке точки $c$, $x \ge 0$, $y \ge 0$, $x$,
   $y$ — целые, определяет вторую координату точки.


## Формат ввода:
В первой строке даются два числа $x$ и $y$ для первой части задачи
($0 \le x, y \le 10^9$). Во второй строке даются два числа $x$ и $c$ для второй
части задачи ($0 \le x \le 10^9$, $0 \le c \le 2 \cdot 10^9$).


### Пример:
#### Ввод:
```
3 4
5 23
```
#### Вывод:
```
7
18
```
